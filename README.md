Solara Bay is an original open-world crime game in the browser: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police as your wanted level rises, and run missions for the city's crews. Play as Ren Maro — tall, red-haired, in a long maroon robe — and steal the matte-black Vanta GT hero car parked on Marina Row at sunset.

## Run it

```sh
node serve.ts
```
Then open http://localhost:8080.
